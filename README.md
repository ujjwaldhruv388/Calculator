# Calculator Project  

This is a simple yet elegant calculator project developed using **JavaScript**, **CSS**, and **HTML**. The calculator provides a clean user interface and supports basic arithmetic operations, making it a handy tool for quick calculations.  

### Features  
- User-friendly design with a responsive layout.  
- Supports addition, subtraction, multiplication, and division.  
- Built with clean and modular code for easy understanding and customization.
